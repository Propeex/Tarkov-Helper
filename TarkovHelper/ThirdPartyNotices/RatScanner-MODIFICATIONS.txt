RatScanner-derived scanner notice
================================

This application includes a modified and reduced implementation derived from the
RatScanner project. The integration keeps only Korean item-name recognition and a
minimal floating name display. The original dashboard, item information overlay,
icon scan, language selector, updater, and community/support links are not included.

Original project: RatScanner/RatScanner
License: Based on Elastic License 2.0 (see RatScanner-LICENSE.txt)
Modified distribution: TarkovHelper_JH by Propeex

v1.7.1 통합 변경:
- RatScanner 미니멀 UI의 이름/플리마켓 평균가/칸당 가격/최고 상인 판매가/카파/필요량 표시 구조를 Helper용 WPF 창으로 재구현했습니다.
- 아이콘 스캔, 검색 오버레이, TarkovTracker 토큰 연동, 팀 추적은 포함하지 않았습니다.
- 퀘스트·은신처 필요량과 현재 보유량은 TarkovHelper의 로컬 프로필 데이터로 계산합니다.
- 가격은 tarkov.dev 정적 JSON 데이터의 avg24hPrice 및 sellToTrader.priceRUB를 사용하고 마지막 정상 응답을 캐시합니다.
- 미니멀 UI를 Helper 본창과 독립적으로 표시하며 클릭 투과를 지원합니다.
- 게임 프로세스 메모리에는 접근하지 않고 화면 캡처와 OCR만 사용합니다.
